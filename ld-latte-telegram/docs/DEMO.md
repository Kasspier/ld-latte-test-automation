# Сценарий показа по ТЗ

Все команды выполняются из каталога `ld-latte-telegram`. Перед показом убедитесь, что интеграционный тест не запущен: он временно меняет каталог. После каждого изменения заново отправляйте `/start` в Telegram.

## 1. Динамическое количество кнопок

```powershell
npm.cmd run catalog -- count 2
```

Отправить `/start`, показать две кнопки, нажать обе. Бот отвечает названиями соответствующих услуг.

```powershell
npm.cmd run catalog -- count 5
```

Снова `/start`: пять кнопок. Нажать первую и последнюю.

```powershell
npm.cmd run catalog -- count 9
```

Снова `/start`: девять кнопок. Workflow на протяжении показа не редактируется и не перезапускается.

## 2. Переименование

```powershell
npm.cmd run catalog -- rename 00000000-0000-4000-8000-000000000001 'Бот записи — новое название'
```

Показать новое название после `/start`. Нажать кнопку этой услуги из старого сообщения: в ответе будет уже текущее название из БД. Это доказывает поиск по ID.

## 3. Отключение

```powershell
npm.cmd run catalog -- disable 00000000-0000-4000-8000-000000000002
```

После `/start` кнопки нет. Нажатие старой кнопки предлагает обновить меню. Для возврата:

```powershell
npm.cmd run catalog -- enable 00000000-0000-4000-8000-000000000002
```

## 4. Добавление и удаление

```powershell
npm.cmd run catalog -- add 'Автоматическая сверка оплат'
```

Команда напечатает ID добавленной услуги. После `/start` появляется новая кнопка, нажатие возвращает её название. Подставьте этот ID в команду ниже — не ID другой услуги:

```powershell
npm.cmd run catalog -- delete UUID_ДОБАВЛЕННОЙ_УСЛУГИ
```

После нового `/start` добавленная кнопка исчезает. Старая кнопка безопасно сообщает, что услуга недоступна.

## 5. Нет активных услуг

```powershell
npm.cmd run catalog -- count 0
```

`/start` возвращает понятный текст, без пустой клавиатуры и технической ошибки. Верните исходное меню:

```powershell
npm.cmd run catalog -- count 2
npm.cmd run catalog -- rename 00000000-0000-4000-8000-000000000001 'Бот для записи клиентов'
```

## Что показать в n8n

Открыть workflow и объяснить цепочку: событие → определение действия → актуальное чтение базы → динамическое тело сообщения и клавиатура → ответ транспорту. В Code нет захардкоженных названий девяти услуг. В Postgres — только read-only подключение. Экспорт не содержит токена Telegram и паролей.

## Критерии сдачи

| Требование | Как показывается |
| --- | --- |
| ID, название, активность | `npm run catalog -- list`, схема таблицы |
| Актуальное чтение на каждом /start | Изменить таблицу, снова отправить /start |
| 2 / 5 / 9 кнопок | Три переключения count без изменения workflow |
| Динамическое тело и inline keyboard | Code-узел Build dynamic response |
| Выбор услуги по ID | Разные кнопки и переименование при сохранении старого меню |
| Добавление / удаление / отключение | Команды над таблицей и повторный /start |
| Пустой каталог | count 0, понятный ответ |
| Передаваемые материалы | Workflow JSON, схема/данные, README, compose и relay |
