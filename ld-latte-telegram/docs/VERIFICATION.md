# Проверка

Дата: 7 ноября 2026 года. Среда: Docker Desktop на Windows, n8n 2.46.6, PostgreSQL 16, Node.js 24. Контейнеры отдельного проекта `ld-latte-telegram`; другие проекты не менялись.

## Пройдено

- 14 автоматических тестов: 2/5/9 кнопок, ноль и неактивные услуги, большой каталог, выбор по ID и актуальному названию, старые кнопки, команды и упоминания, отказ группам, неверный callback, ограничения транспорта, подтверждение callback, allowlist и сохранение offset.
- 12 интеграционных сценариев **с настоящими n8n и PostgreSQL**: 2/5/9/0 активных услуг; выбор разных ID; переименование с проверкой старой кнопки; добавление; отключение; удаление; попытка SQL-инъекции; отказ webhook без корректного секрета; read-only роль БД.
- В интеграционном прогоне каталог менялся и возвращён в исходное состояние. Workflow между запросами не импортировался и не редактировался.
- Публичный JSON workflow сформирован из проверенного исходника. Секреты находятся только в исключённых `.env` и `.private/credentials.local.json`.

Машиночитаемый отчёт и сформированные меню: `output/integration-report.json`. Сообщения в нём — результат реального выполнения n8n для синтетического чата, не снимки переписки Telegram.

Первый запуск теста атомарного сохранения offset был заблокирован Windows-песочницей (`EPERM` при rename). Повтор вне этого ограничения прошёл: 14/14. Логика не обходила атомарную запись и не меняла её на небезопасную.

## Подключение к Telegram

7 ноября владелец сохранил токен локально. Контейнер relay пересоздан с обновлённым окружением. Telegram успешно ответил на `getMe` и `getWebhookInfo`; relay подтвердил подключение как `@ld_latte_tested_bot` и запустил long polling. Значение токена в отчёт и вывод не включено. Allowlist пуст: разрешены личные чаты любых пользователей; группы не обрабатываются. В каталоге две активные услуги.

## Полный показ в Telegram — выполнен

Владелец подтвердил в чате 7 ноября: после `/start` в `@ld_latte_tested_bot` появились две услуги, обе inline-кнопки работают и присылают соответствующие названия. Тем самым подтверждены реальное получение события Telegram, выполнение workflow, отправка клавиатуры и обработка выбора.

7 ноября 2026 года дополнительно выполнен полный прогон через Telegram Desktop в настоящем `@ld_latte_tested_bot`:
