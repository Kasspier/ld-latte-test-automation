# Задача №2 — план подключения Instagram

Готовый комплект по всем критериям задачи №2. Откройте `index.html` двойным щелчком в браузере.

- `index.html` — понятный бизнес-план: две SVG-схемы, роли и шаги, показатели, расписание, проверка и вопросы компании. Прежние удалённые по просьбе пользователя разделы не восстановлены.
- `technical.html` — приложение для специалиста: три способа подключения, scopes, получение/поддержание токенов, запросы до первых метрик, таблица API, модель хранения, диагностика и план приёмки.
- `ACCEPTANCE.md` — соответствие каждому критерию исходного ТЗ и границы проведённой проверки.
- `scripts/build-technical.py` — генератор приложения без внешних зависимостей; повторная сборка: `python scripts/build-technical.py`. Стили берутся из бизнес-HTML.
- `delivery/LD-LATTE-Instagram.zip` — комплект для передачи.

Оба HTML автономны: стили и схемы встроены, сервер для чтения не нужен. Для перехода между ними храните оба файла рядом. Только ссылки на источники Meta требуют интернета. Кнопка печати открывает стандартный диалог браузера; отдельный PDF не создавался, пагинация PDF не проверялась.

Дата сверки официальной документации Meta — 7 ноября 2026 года. Версия материалов 1.2. Учтены Unified Login с SUAT, его обязательные права и альтернатива Instagram Login. Пример версии API в текущей справке — v27.0; перед внедрением её проверяют повторно.

Проверено чтение и навигация в браузере на компьютере и при viewport 390×844. Переполнения страницы нет; широкие таблицы и SVG прокручиваются внутри блоков. Внутренние якоря и относительные ссылки проверены.

По ТЗ требуется исследование и план. Работающая интеграция, приложение Meta, токены и реальные запросы к аккаунтам компании не требуются и не создавались. Описанные тесты интеграции — план её будущей приёмки, а не выполненные прогоны.
